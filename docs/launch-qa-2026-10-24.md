## Earlier baseline blockers / issues (see latest status above)

1. **Private image disclosure:** before the demo was made public, QA B and anonymous clients could not read its private journal records, but an unauthenticated request to its stored public image URL returned HTTP 200 and PNG bytes. Private journal images currently use the public images bucket. The private `journal-attachments` bucket passed its separate access checks; that does not protect inline images stored elsewhere.
2. **Timeline link retains temporary journal ID:** creating an event while a journal has a `recovery-…` ID leaves that ID in `projects.timeline[].journalEntryId` and the entry's linked event snapshot after publication to a UUID. Example: Technical Analysis entry `8246cbfb-caa9-42bc-8b66-125f2cee43f8`. The reverse link must be remapped before launch.
3. **Automated suite failures:** full suite finished with 406 passes and 60 failures. Do not treat focused passing tests as a clean overall baseline. The expanded community/chat/materials/activity subset had 66 passes and five failures; those require triage rather than assuming they are all product bugs or all stale tests.
4. **Upload feedback:** malformed image did not leave a clear error in the inspected UI. A valid retry succeeded.
