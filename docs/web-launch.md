# Juniper Journal web launch

Target experience: junejournal.org opens Flutter Explore; signing in opens the app workspace. Supabase remains the backend.

## Preview first

Firebase project configured in .firebaserc: the-juniper-journal.
Hosting serves build/web. firebase.json provides an index.html fallback and avoids caching the main application entry files.

1. Authenticate the Firebase CLI using the Google account with access to this project: `firebase login`.
2. Run `FLUTTER_BIN=/Users/benjaminyang/.codex/flutter-juniper-runtime/bin/flutter sh tool/deploy_web_preview.sh`.
3. Use the returned preview URL. Configure that exact origin in Supabase Authentication URL Configuration for email verification and password-reset redirects, without removing current production URLs.
4. Verify signed-out browsing, signup, email verification, signin, signout, password reset, journal saving, uploads, collaboration, role permissions, copied links, refresh, Back and Forward.

The preview expires after seven days and does not replace the live Hosting channel or change Wix DNS.

## Domain cutover after preview validation

- Preserve the current Wix About, Workshops, Safety, Privacy and Support pages, or provide their replacements.
- Deploy the reviewed build to Firebase Hosting's live channel.
- Add junejournal.org as a custom domain in Firebase Hosting and follow its verification/DNS instructions at the domain's actual DNS provider.
- Configure www.junejournal.org to redirect to the canonical junejournal.org address.
- Preserve email MX records and email-verification TXT records when changing website DNS.
- Configure Supabase's production Site URL and exact allowed authentication redirects for https://junejournal.org.
- Check HTTPS, existing content links, and authentication on the final domain.
- Retain the old Wix DNS values for rollback until launch is verified.

Never put service-role keys or database passwords into the web build. tool/build_web.sh uses the public configuration generated by tool/web_config.py.
